# Problem reports and change requests

Register defined by `docs/lifecycle/01-plans/scmp.md`, section 5. Started
2026-11-20; earlier defects are in the git history and are not back-filled.

Classification: **S** safety-related (can make a report wrong or misleading;
a failure condition of `04-safety/hazard-assessment.md`), **F** functional,
**P** process or documents, **C** change request. Status: Open, Analysed,
Fixed (with the test), Verified, Closed (at a release, with the tag).

Every report below was found by reading the code while the low-level
requirements were written. "Confirmed" means the code path was read end to end;
"suspected" means it depends on an input that was not shown to occur. Issue 1
fixed the reports marked Fixed, each with a regression test that fails on the
old code; the fix and the test are named in the Status column. The rest stay
open.
